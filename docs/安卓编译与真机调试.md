# 安卓端编译与真机调试指南

这份文档记录从零把安卓 App 编译出来、装进手机、连上后端的完整过程，以及一路上真正踩过的坑。

> 适用：`android/` 目录下的 Capacitor + 原生 Java 混合工程。

---

## 一、准备环境

| 组件 | 版本要求 | 说明 |
|---|---|---|
| JDK | **17** | Gradle 8.2.1 要求，用 11 或 21 都可能报错 |
| Android SDK | API 34 + Build Tools | 用 Android Studio 装最省事 |
| Node.js | 18+ | 给 Capacitor 用 |
| Gradle | 8.2.1 | 工程自带 wrapper，不用单独装 |

检查环境：

```bash
java -version                    # 应显示 17.x
echo %ANDROID_HOME%              # 应指向 SDK 目录
node -v
```

如果 `ANDROID_HOME` 没配，在 `android/local.properties` 里直接写死：

```properties
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
```

## 二、编译 APK

```bash
cd android

# 1. 装 Capacitor 依赖
npm install

# 2. 把 www/ 里的前端页面同步进安卓工程
#    （修改了前端页面后必须重新执行这一步，否则 App 里还是旧页面）
npx cap sync android

# 3. 编译 Debug 包
cd android
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
```

产物路径：

```
android/app/build/outputs/apk/debug/app-debug.apk
```

### 常见编译错误

**① `Unsupported class file major version`**
JDK 版本不对。确认 `java -version` 是 17。

**② Gradle 下载卡住**
工程已配置阿里云镜像，但如果 wrapper 本身下载不动，手动改
`android/gradle/wrapper/gradle-wrapper.properties` 里的 `distributionUrl`。

**③ `SDK location not found`**
补 `local.properties`（见上）。

**④ 改了前端页面但 App 里没变**
忘了 `npx cap sync android`。前端改动必须先同步再编译。

## 三、装到手机并连接

### 1. 安装

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### 2. 填后端地址

打开 App → 设置 → 填后端地址。

| 场景 | 地址写法 |
|---|---|
| 手机和电脑在同一 Wi-Fi | `192.168.x.x:12393`（电脑的局域网 IP）|
| 电脑开热点给手机 | 网关地址，通常是 `192.168.137.1:12393` |
| USB 连接（推荐调试用） | `127.0.0.1:12393` + `adb reverse tcp:12393 tcp:12393` |

**USB 端口转发**是最稳的方式（不受 Wi-Fi 影响）：

```bash
adb reverse tcp:12393 tcp:12393
adb reverse tcp:12394 tcp:12394
```

之后 App 里填 `127.0.0.1:12393` 即可。

### 3. 授权

App 首次运行需要三个权限：

- **麦克风** —— 语音对话
- **悬浮窗**（在其他应用上层显示）—— 挂机模式
- **屏幕录制** —— 让她看见你的游戏

屏幕录制在部分机型（尤其华为/荣耀）每次启动都要重新授权，工程里用一个透明的中转 Activity 承接这个回调。

## 四、真机踩坑记录

这些都是实际调试时遇到的，按现象对照排查。

### ① 页面一直停在 Capacitor 配置页

**现象**：App 打开了，但显示的是一张配置页，点了没反应。

**原因**：WebView 拒绝了导航。Capacitor 的 `server.allowNavigation` 是一个白名单，
**只有列进去的网段才能被导航**。

**关键点**：如果用的是 `adb reverse`（地址是 `127.0.0.1`），那白名单里**必须包含 `127.0.0.1`**，
否则永远停在 Capacitor 自己的 `https://localhost` 页面。这个坑很隐蔽，因为大多数教程只写局域网网段。

```ts
// android/capacitor.config.ts
allowNavigation: [
  '127.0.0.1',     // ← adb reverse / 本机后端场景必须有
  'localhost',
  '192.168.*',
  '10.*',
]
```

### ② HTTPS / WebSocket 连不上

后端开了 HTTPS 时，自签证书会导致 WebSocket 握手失败。

**重要**：这类失败**不会**触发安卓的 `onReceivedSslError` 回调，
所以「忽略证书错误」那种写法根本无效。

**正确做法**：把后端的 CA 证书装进系统的信任锚（Network Security Config）。
自签的服务端证书是跟 IP 绑定的，**换网络后 IP 变了要重新签发**。

### ③ 声音从听筒出来 / 声音很小

安卓在 `MODE_IN_COMMUNICATION` 音频模式下会自动把输出切到听筒。
原生层写了音频路由守护（强制走扬声器），如果仍然异常，检查是否有其他应用抢占了音频焦点。

### ④ 麦克风状态和界面对不上

网页端按钮的颜色/`localStorage` 都**不能**作为麦克风是否真正开启的判断依据。
工程里用原生侧维护"请求序号 + 真实状态"，网页端通过 hook `getUserMedia` / `track.stop` 来同步。

### ⑤ 播放音频偶发崩溃

早期把 `play()` 重复包了好几层，导致调用栈溢出。现在播放链路做了幂等处理。

### ⑥ USB 调试老是掉线

老机型 USB 口容易接触不良。调试期间建议：

```bash
# 看设备状态，反复出现 unauthorized 就是线/口的问题
adb devices

# 或者改用无线调试（先用 USB 执行一次）
adb tcpip 5555
adb connect <手机IP>:5555
```

## 五、打包 Release（可选）

Debug 包已经够日常使用。要做发布包需要：

1. 生成签名密钥

```bash
keytool -genkey -v -keystore my-release.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias mykey
```

2. 在 `android/app/build.gradle` 里配置 `signingConfigs`
3. 构建

```bash
./gradlew assembleRelease
```

> ⚠️ 签名文件和密码**绝对不要**提交到仓库。`.gitignore` 里已经排除了 `*.jks` / `*.keystore`。

## 六、改前端页面后的正确流程

前端有两份：

- `android/www/` —— Capacitor 的源
- `android/app/src/main/assets/public/` —— sync 之后生成的目标

**正确流程**：

```bash
# 1. 改 android/www/ 下的文件（或从后端 frontend/ 同步过来）
# 2. 同步进安卓工程
npx cap sync android
# 3. 重新编译
./gradlew assembleDebug
```

只改 `assets/public/` 里的话，下次 sync 会被覆盖掉。
